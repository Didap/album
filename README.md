# Album carte Pokémon

Raccoglitore sfogliabile per Expedition, Aquapolis e Neo Destiny, con le carte possedute segnate come presenti.

- Pagina unica: `index.html` (dati e codice inclusi, nessuna build).
- Immagini caricate da `images.pokemontcg.io`.
- Le carte presenti sono nell'array `DATA` dentro `index.html`: il quinto campo di ogni riga è `null` (mancante), `""` (presente) o `"rev"` (presente, reverse holo).
- Link diretti ai set: `#expedition`, `#aquapolis`, `#neo-destiny`.
